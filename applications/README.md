# Applications

One folder per application, named `YYYY-MM-DD-company-role/`, e.g. `2026-10-24-acme-account-manager/`.

Each folder should contain:
- `job-posting.md` — the original job description (pasted/saved)
- `cv.md` or `cv.pdf` — tailored CV for this application
- `cover-letter.md` — tailored cover letter
- `notes.md` — research notes, contacts, interview prep, follow-ups

Add a row to `../job-search-log.md` when you create a new application folder.
