# Career

Personal workspace for managing my long-term career: CV, cover letters, job applications, and related automation.

## Structure

- `cv/` — source CV and exported versions
- `cover-letters/` — cover letter drafts and tailored versions
- `applications/` — one folder per job application (posting, tailored docs, notes, status)
- `job-search-log.md` — running log/tracker of applications and outcomes
- `automations/` — job-hunt engine (search, dedupe, queue); see `automations/README.md`
- `.claude/skills/job-hunt/` — the Claude skill that drives searching, scoring and drafting
- `app/` — morning review page (Interested / Maybe / Pass)
- `profile/` and `templates/` — your personal context and the blank templates for it
- `config/` — which job sources are on (incl. the optional Chrome mode)
- `data/` — generated queue and your decisions
