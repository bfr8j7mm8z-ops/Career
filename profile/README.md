# Profile

Your personal context lives here. The job-hunt engine is generic; this folder is what makes it yours.

| File | What it is | Template |
|---|---|---|
| `current-role.md` | What you do now: evidence for fit and CV writing | `templates/profile/current-role.md` |
| `current-search-focus.md` | What you're after right now (rolling, overwrite freely) | `templates/profile/search-focus.md` |
| `target-companies.md` | Career pages to check, companies to skip | `templates/profile/target-companies.md` |
| `../cv/master-cv.md` | Full source CV | `templates/master-cv.md` |
| `../cover-letters/template.md` | Cover letter structure | `templates/cover-letter.md` |

Claude can create these from the templates by asking you, or you can fill them in yourself.
Per `HANDOVER.md`: don't pull role context from work connectors; describe it in chat or paste it.
